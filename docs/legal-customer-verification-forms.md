> เอกสารนี้เป็นแบบร่างสำหรับออกแบบระบบและแบบฟอร์มบนเว็บ Hopnic เท่านั้น ก่อนนำไปใช้จริงควรให้ทนาย/ที่ปรึกษา PDPA/บัญชี ตรวจทานถ้อยคำ เงื่อนไขการเก็บเอกสาร และระยะเวลาเก็บรักษาข้อมูลอีกครั้ง

## 1. เหมาะกับเว็บ Hopnic ไหม

เหมาะ เพราะ Hopnic เป็นระบบเช่าอุปกรณ์/เครื่องมือที่ต้องมีการยืนยันตัวตนก่อนอนุมัติการเช่า โดยเฉพาะกรณีสินค้ามูลค่าสูง นิติบุคคล ลูกค้าโรงงาน ผู้รับเหมา หรือรายการที่มีความเสี่ยงสูง

สิ่งที่ควรมีในระบบ:

- แบบฟอร์มยินยอมเก็บ ใช้ และตรวจสอบข้อมูลลูกค้า
- แบบฟอร์มเก็บข้อมูลลูกค้าแยกบุคคลธรรมดา/นิติบุคคล
- การอัปโหลดเอกสาร KYC พร้อม checkbox รับรองว่าเอกสารถูกต้อง
- การเก็บ consent log เช่น `user_id`, `version`, `accepted_at`, `ip_address`, `user_agent`
- การกำหนดระดับลูกค้า เช่น Guest, Verified Individual, Verified Company, High-risk

ข้อควรระวัง:

- ขอข้อมูลเท่าที่จำเป็นต่อการเช่าเท่านั้น
- เอกสารสำคัญ เช่น บัตรประชาชน หนังสือรับรองบริษัท ภ.พ.20 ต้องเก็บใน storage ที่จำกัดสิทธิ์เข้าถึง
- ควรมี audit log เมื่อ admin เปิดดู ดาวน์โหลด หรือแก้ไขข้อมูล KYC
- ควรแยก “ความยินยอม” ออกจาก “การปฏิบัติตามสัญญา/กฎหมาย” ให้ที่ปรึกษา PDPA ตรวจอีกครั้ง

## 2. จุดที่ควรแสดงเอกสารนี้บนเว็บ

| จุดในระบบ               | เอกสาร/ข้อความที่ใช้                                | หลักฐานที่ควรเก็บ                               |
| ----------------------- | --------------------------------------------------- | ----------------------------------------------- |
| สมัครสมาชิก             | ยอมรับ Privacy Policy / PDPA                        | user id, version, accepted time, IP, user agent |
| หน้า Verification       | Customer Verification & KYC Consent                 | consent type, version, customer id              |
| หน้า Upload เอกสาร      | คำรับรองว่าเอกสารจริง ถูกต้อง เป็นปัจจุบัน          | uploaded file id, consent log                   |
| Checkout ก่อนยืนยันเช่า | ยืนยันว่าข้อมูลลูกค้าถูกต้อง                        | booking id, agreement version                   |
| Admin/POS Booking       | พนักงานยืนยันว่าแจ้งเงื่อนไขและได้รับความยินยอมแล้ว | admin id, channel, evidence file                |

### ข้อตกลงและความยินยอมในการเก็บข้อมูลลูกค้า

เพื่อใช้ในการยืนยันตัวตน การอนุมัติการเช่า การออกเอกสาร และการป้องกันความเสี่ยง ข้าพเจ้า/บริษัทผู้เช่า ตกลงและยินยอมให้ บริษัท ฮอปนิค จำกัด เก็บรวบรวม ใช้ ตรวจสอบ และจัดเก็บข้อมูลส่วนบุคคล เอกสารยืนยันตัวตน และเอกสารประกอบการเช่า ตามวัตถุประสงค์ที่เกี่ยวข้องกับการให้บริการเช่าอุปกรณ์ เครื่องมือ เครื่องจักร หรือสินค้าอื่น ๆ ของบริษัท

### 3.1 ข้อมูลที่บริษัทอาจเก็บรวบรวม

#### กรณีบุคคลธรรมดา

- ชื่อ–นามสกุล
- เลขบัตรประชาชน
- วันเดือนปีเกิด
- ที่อยู่ตามบัตรประชาชน
- ที่อยู่สำหรับจัดส่ง/รับคืนสินค้า
- เบอร์โทรศัพท์ อีเมล และ Line ID หากมี
- สำเนาบัตรประชาชน หรือหลักฐานยืนยันตัวตนเพิ่มเติมหากจำเป็น
- ข้อมูลการชำระเงิน
- ประวัติการเช่า การคืนสินค้า และความเสียหายที่เกิดขึ้น

#### กรณีนิติบุคคล

- ชื่อนิติบุคคลและเลขทะเบียนนิติบุคคล
- ที่อยู่สำนักงานใหญ่/สาขา
- หนังสือรับรองบริษัท
- ภ.พ.20
- สำเนาบัตรประชาชนของกรรมการหรือผู้มีอำนาจลงนาม
- หนังสือมอบอำนาจ หากผู้ติดต่อไม่ใช่กรรมการผู้มีอำนาจ
- ข้อมูลผู้ติดต่อประสานงาน เบอร์โทรศัพท์ อีเมล และที่อยู่จัดส่ง
- ข้อมูลการออกใบเสนอราคา ใบแจ้งหนี้ ใบเสร็จรับเงิน ใบกำกับภาษี และเอกสารภาษี

### 3.2 วัตถุประสงค์ในการเก็บและใช้ข้อมูล

บริษัทจะใช้ข้อมูลของลูกค้าเพื่อวัตถุประสงค์ดังต่อไปนี้:

- ยืนยันตัวตนของลูกค้าก่อนอนุมัติการเช่า
- ประเมินความเสี่ยงก่อนให้เช่าอุปกรณ์
- จัดทำใบเสนอราคา ใบจอง ใบแจ้งหนี้ ใบเสร็จรับเงิน ใบกำกับภาษี และเอกสารที่เกี่ยวข้อง
- จัดส่ง รับคืน ติดตามสถานะ และตรวจสอบทรัพย์สินที่ให้เช่า
- ป้องกันการทุจริต การนำเอกสารปลอมมาใช้ หรือการนำสินค้าไปใช้ผิดวัตถุประสงค์
- ติดต่อลูกค้าเกี่ยวกับการเช่า การชำระเงิน การคืนสินค้า การต่ออายุการเช่า หรือการเรียกเก็บค่าเสียหาย
- ใช้เป็นหลักฐานในกรณีเกิดข้อพิพาท การผิดสัญญา การชำระเงินล่าช้า หรือความเสียหายต่อสินค้า
- ปฏิบัติตามกฎหมาย ภาษี บัญชี หรือคำสั่งของหน่วยงานราชการที่เกี่ยวข้อง

### 3.3 การยืนยันและรับรองของลูกค้า

ลูกค้ารับรองว่า:

- ข้อมูลและเอกสารทั้งหมดที่ส่งให้บริษัทเป็นข้อมูลจริง ถูกต้อง และเป็นปัจจุบัน
- ลูกค้ามีสิทธิ์ในการใช้เอกสารดังกล่าวเพื่อประกอบการเช่า
- กรณีนิติบุคคล ผู้ดำเนินการแทนบริษัทมีอำนาจหรือได้รับมอบอำนาจอย่างถูกต้อง
- ลูกค้าจะไม่ใช้เอกสารปลอม เอกสารของบุคคลอื่น หรือข้อมูลที่ทำให้บริษัทเข้าใจผิด
- ลูกค้าจะไม่ให้บุคคลอื่นนำบัญชีผู้ใช้หรือเอกสารของตนไปใช้เช่าแทนโดยไม่ได้รับอนุญาตจากบริษัท

### 3.4 ข้อห้ามเกี่ยวกับการใช้บริการเช่า

ลูกค้าตกลงว่าจะไม่กระทำการดังต่อไปนี้:

- นำอุปกรณ์ที่เช่าไปให้บุคคลอื่นเช่าต่อ ขายต่อ จำนำ โอน หรือส่งมอบต่อโดยไม่ได้รับอนุญาต
- นำอุปกรณ์ไปใช้งานผิดประเภท ผิดกฎหมาย หรือใช้งานเกินขีดจำกัดที่ระบุ
- ถอด แกะ ทำลาย เปลี่ยนแปลง หรือปิดบัง Serial Number, Asset Tag, RFID Tag, QR Code หรือสัญลักษณ์ทรัพย์สินของบริษัท
- ดัดแปลง ซ่อมเอง แกะเครื่อง หรือเปลี่ยนชิ้นส่วนโดยไม่ได้รับอนุญาต
- ปฏิเสธการคืนสินค้า หรือหลีกเลี่ยงการติดต่อเมื่อครบกำหนดเช่า
- ใช้ข้อมูลหรือเอกสารเท็จในการสมัครสมาชิกหรือทำรายการเช่า

### 3.5 ระดับการยืนยันตัวตนลูกค้า

| ระดับลูกค้า                   | เอกสาร/ข้อมูลที่ต้องใช้                               | สิทธิ์การใช้งาน                        |
| ----------------------------- | ----------------------------------------------------- | -------------------------------------- |
| Guest                         | เบอร์โทรศัพท์ / อีเมล                                 | ดูสินค้า / ขอใบเสนอราคา / จองเบื้องต้น |
| Verified Individual           | บัตรประชาชน + เบอร์โทร + ที่อยู่                      | เช่าในนามบุคคลธรรมดา                   |
| Verified Company              | หนังสือรับรองบริษัท + ภ.พ.20 + ผู้ติดต่อ + ผู้มีอำนาจ | เช่าในนามนิติบุคคล                     |
| High-risk / High-value Rental | เอกสารเพิ่มเติม / เงินมัดจำ / ประกัน / ผู้ค้ำประกัน   | ใช้กับสินค้ามูลค่าสูงหรือความเสี่ยงสูง |

### 3.6 การเก็บรักษาข้อมูล

บริษัทจะเก็บรักษาข้อมูลของลูกค้าเท่าที่จำเป็นต่อการให้บริการ การดำเนินธุรกรรม การปฏิบัติตามกฎหมาย และการป้องกันข้อพิพาท โดยบริษัทจะใช้มาตรการที่เหมาะสมในการป้องกันการเข้าถึง ใช้ เปิดเผย แก้ไข หรือทำลายข้อมูลโดยไม่ได้รับอนุญาต

### 3.7 การเปิดเผยข้อมูลแก่บุคคลภายนอก

บริษัทอาจเปิดเผยข้อมูลของลูกค้าเท่าที่จำเป็นให้แก่:

- ผู้ให้บริการขนส่ง
- ผู้ให้บริการชำระเงิน
- ผู้ให้บริการระบบบัญชี/ใบกำกับภาษี
- ผู้ให้บริการระบบเว็บไซต์หรือ Cloud Storage
- ที่ปรึกษากฎหมาย บัญชี หรือภาษี
- หน่วยงานราชการ ศาล หรือหน่วยงานที่มีอำนาจตามกฎหมาย
- บริษัทประกัน หรือผู้เกี่ยวข้องกับการเคลมความเสียหาย ในกรณีที่ลูกค้าเลือกซื้อความคุ้มครอง

### 3.8 สิทธิของลูกค้าตาม PDPA

ลูกค้ามีสิทธิตามกฎหมายคุ้มครองข้อมูลส่วนบุคคล เช่น:

- ขอเข้าถึงข้อมูล
- ขอแก้ไขข้อมูล
- ขอถอนความยินยอม
- ขอให้ลบหรือทำลายข้อมูล ในกรณีที่กฎหมายอนุญาต
- ขอคัดค้านการใช้ข้อมูลบางประเภท
- ขอรับสำเนาข้อมูลของตนเอง

ลูกค้าสามารถติดต่อบริษัทเพื่อใช้สิทธิได้ผ่านช่องทางที่บริษัทกำหนด

### 3.9 การยินยอม
